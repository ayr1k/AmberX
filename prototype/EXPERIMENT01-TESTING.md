# AmberX Experiment 01 — 本地测试 / Local testing

版本 / Version: 0.1.0-alpha.1

1. 安装到新的 AmberX 目录，确认开始菜单及窗口标题为 AmberX。Install into its own directory; verify its identity.
2. 首页选择「让它更流畅」，确认配方并生成方案。Choose the smoother-gameplay goal and generate setups.
3. 切换三档候选，阅读实际文件、版本及省略项。Compare tiers, files, versions and omissions.
4. 选择方案，勾选已阅读提示后安装。Confirm the reviewed file list and install.
5. 从实验页启动试用；退出游戏后记录反馈。Launch the trial, exit the game and record feedback.
6. 对已安装实例选择「在副本中实验」。确认原实例文件不变；副本必须重新检查并再次确认。Experiment in a copy; verify the source stays intact and the copy requires another review.
7. 在下载期间取消，重启后从任务页继续。Cancel a download and resume from Tasks after restart.
8. 切换中英文、深浅主题，测试下拉列表方向键、Enter、Escape。Test language, theme, arrow keys, Enter and Escape.
9. 以 100%、125%、150%、200% 显示比例检查布局。标签不可误选，玩家名和日志应可复制。Check scaling, nonselectable labels and selectable inputs/logs.

远景组合由实时兼容信息决定，不保证每个版本都有推荐。第一版暂不导入其他产品实例，不合并或回写原存档。离线玩家名不能替代官方服务器认证。Distant terrain availability depends on current compatible files. No cross-product imports, source writes or world merges. Offline names do not replace official authentication.

关闭窗口会询问是否中断正在安装的任务。独立数据目录卸载后保留。Closing during installation asks before cancellation; uninstalling retains data.
