# AmberX Experiment 02 本地验收 / Local testing

版本 / Version: 0.2.0-alpha.1

1. 安装到 AmberX 原程序目录或新的空目录；不要选择 AMBER / AmberE 目录。第一版安装包保留在 releases/Experiment01。
2. 首页编辑目标，选择功能并锁定一个需要的功能；锁定游戏版本与加载器，生成桌面。检查没有静默换版本。
3. 比较三个方案，切换「只看不同内容」，查看说明面板。复制综合方案到另一个位置，调整功能，再检查。使用撤销。
4. 在调整面板中填写一半后关闭并重开启动器，确认草稿恢复。断网检查时应保留原方案并显示错误。
5. 选择一个已安装 AmberX 实例作为起点。检查副本空间，确认清单，安装并试用。原实例应保持不变。
6. 退出游戏后记录体验，保留为常用实例。也可调整后创建另一个试用实例。
7. 删除一个测试实例，在回收站恢复并确认存档仍在；再次删除后输入完整名称彻底删除。不要用重要存档测试彻底删除。
8. 安装中取消、退出重启，从任务中心继续。副本已创建但重新推荐失败时，用「重新检查已有副本」。
9. 检查中英文、浅深色、125% / 150% / 200% 缩放、键盘 Tab / Enter / Escape。普通界面文字不应被拖选，输入与日志仍可复制。

## English

Install over AmberX or into an empty directory, never over another launcher. Test goal and required-feature locks, three-way comparison, online variant adjustment, undo and restored drafts. Try changes in an independent copy and verify the source stays unchanged. Review after exiting, keep, recycle, restore and permanently delete a disposable instance. Exercise cancellation, restart and resume. Check both languages, themes, zoom and keyboard controls.

No automatic FPS measurement or original-world merging is included. Experiment 01 artifacts are retained separately; do not run both versions against the same library at once.
