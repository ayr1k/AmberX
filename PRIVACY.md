# AmberX 隐私与数据 / Privacy and data

Experiment 01 只使用本地离线玩家名，不提供微软和第三方账号输入接口。它不会读取 AMBER 或 AmberE 的账号库，也不上传问卷硬件信息或实验反馈。

实例、配置、记录和日志位于 `%APPDATA%\AmberX\library`。卸载保留这些数据。没有云同步、遥测和自动更新源。推荐及安装会访问 Mojang、Modrinth、Java 提供方和加载器的下载服务；这些服务可看到普通网络请求信息。

本地日志可能包含玩家名、服务器地址和个人文件路径。分享日志前检查内容。模组和游戏本身可发起网络连接，其行为不由启动器的隐私承诺覆盖。只安装可信内容。

Experiment 01 uses only a local offline player name. It provides no Microsoft or third-party credential input and does not read AMBER or AmberE account stores. Hardware survey results and experiment feedback are not uploaded.

Instances, settings, records and logs live in `%APPDATA%\AmberX\library`, retained on uninstall. No cloud sync, telemetry or automatic update feed. Recommendations/downloads contact Mojang, Modrinth, Java providers and loader services, which receive normal network request information.

Logs may contain player names, server addresses and personal file paths. Review before sharing. Games and mods can make their own network requests outside the launcher's privacy behavior. Install trusted content only.
